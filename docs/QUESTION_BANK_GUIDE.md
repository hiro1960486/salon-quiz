# 昭和なつかしクイズ — 問題データと出題エンジンの管理

## 現在の範囲
- 問題データ: 5モジュール・計470問（新規2,000問の一括生成はまだ実施していない）
- 画面: `index.html`（UI/設定）
- 出題・採点・履歴: `quiz-engine.js`
- 統合入口: `quiz-data.js`（ジャンル別配列を結合）
- 問題本体: `data/*.js`
- 自動試験: `tests/quiz-smoke.test.cjs`、GitHub Actions

## ジャンル別データ追加
新しい分野（例: 春日井の地名、名古屋の電気街、鉄道、昭和の主婦の暮らし）は `data/` に独立ファイルを追加し、
`index.html` のスクリプト読み込みと `quiz-data.js` の配列結合に明示的に登録すること。

現在の問題の基本型:

```js
{
  genre: "暮らし",
  question: "問題文",
  choices: ["選択肢A", "選択肢B", "選択肢C"],
  correct: 0,
  difficulty: "normal", // "hard" または "super" も可
  region: "東海",         // 地域クイズに必要なら付与
  talk: "正解の根拠や思い出を語るヒント",
  id: "kasugai-..."      // 推奨。未設定時は問題文＋ジャンルのハッシュ
}
```

## 2,000問を目指す際の品質ルール
1. すべての問題に固有IDを付け、既存IDは問題を修正しても変更しない。
2. 設問の正誤だけでなく、時点・地域・表記ゆれを確認する。
3. 地名読みは自治体・公的地図・鉄道会社の資料で照合し、根拠と確認日を記録する。
4. 似た問題（発売年と昭和何年など）は同一`topic`を付け、同一回での出題を避ける。
5. 写真を使用する場合は使用権限・出典・代替テキストを管理する。画像がなくても遊べる設計を維持する。
6. 出題比率（通常60％、難問30％、超難問10％）は基本値。ご当地と超難問モードは対象データの偏りによって例外あり。
7. 内容別の多様性：地域史、読み方、鉄道・工場、料理・家事、ファッション・買い物、音楽・旅行を混ぜる。
8. 個人の体験談や主観は「正解のある三択問題」と分け、解説欄の会話のきっかけに置く。
9. 追加のたびに件数、完全一致重複、問題文類似、三択、正解番号、10/20/30問の自動試験を実施。
10. 過去のURLや利用者のブラウザー内履歴に影響する大きな変更は別PRで段階的に行う。

## ゲームモード
- おまかせ: ジャンルと難易度をなるべく均等に配置
- のんびり: 時間制限なし
- ご当地名人: 現在は `region: "東海"` の問題
- 超難問: `hard` と `super` の問題
- みんなで相談: 一つの画面を囲んで相談して回答
- 本日の10問: ローカル日付に基づき同一日の順番を固定
- まちがい復習: そのブラウザーで誤答した問題

## ブラウザー保存の注意
端末やブラウザー別のlocalStorageに記録します。ログインによる利用者単位の同期ではありません。
閲覧データの削除・プライベートブラウズで履歴は失われることがあります。
旧版の履歴は推定的に取り込みますが、正誤の詳細までは移行できません。
